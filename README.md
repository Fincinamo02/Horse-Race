#HorseRace

I made this text based horse race to test RNG in coding. I was inspired to make this code after watching  ItzTaken’s YouTube series on how the enemies in Five Nights at Freddy’s functioned where I learned that the enemies move via RNG checks at timed intervals to get closer to a destination.  Using that concept, I made this horse race algorithm where each horse uses RNG at set intervals to reach the end of a track.

Run with Python 3
